# 基于 STC15 与 SG90 的低功耗红外遥控开关

![License](https://img.shields.io/badge/License-GPL%203.0-blue.svg)
![Standby](https://img.shields.io/badge/500mAh%20待机测试-37天-brightgreen.svg)
![MCU](https://img.shields.io/badge/MCU-STC15W408AS-orange.svg)

这是一个面向传统墙壁开关的物理改造项目。设备接收 NEC 红外指令，控制 SG90 舵机模拟手指按压；通过 MCU Power-down、红外中断唤醒和舵机电源切断降低待机功耗。项目包含固件、原理图、PCB 生产文件、焊接实物资料和机械结构设计。

## 实测结果

| 项目 | 结果 |
| --- | --- |
| 供电 | 3.7-4.2 V 锂电池 |
| 待机电流 | 低于 200 μA |
| 单次响应 | 约 200-500 ms |
| 续航测试 | 500 mAh 锂电池待机 37 天 |

37 天数据来自当前样机的完整待机测试，实际续航会随遥控频率、电池状态、舵机负载和环境温度变化。

## 硬件方案

- 主控：STC15W408AS；
- 执行器：SG90 模拟舵机；
- 红外接收：1838B + RC 滤波；
- 电源：3.7 V 锂电池 + TP4056 Type-C 充电模块；
- 舵机电源控制：AO3401 P 沟道 MOSFET，高边切断舵机待机电源；
- PCB：双层板，经过多轮布局与接口调整，并已输出打样生产文件。

## 固件流程

1. 待机时关闭舵机电源，MCU 进入 Power-down；
2. 红外接收头产生外部中断并唤醒 MCU；
3. 定时器测量 NEC 脉宽，完成引导码、数据位和指令校验；
4. 打开舵机电源，根据指令执行开关动作；
5. 动作结束后关闭舵机电源，重新进入休眠。

解码与业务控制采用非阻塞状态组织，避免在等待红外脉宽或舵机动作时长时间占用主流程。

## 低功耗设计

- 将未使用和可能悬空的引脚配置为确定电平，减少输入抖动与漏电；
- 使用 AO3401 对舵机 VCC 做物理断电，避免舵机静态耗电；
- 仅在收到红外信号后唤醒主控，完成动作后立即回到低功耗状态；
- 根据电池电压修正舵机输出，降低电压下降对机械动作的影响。

## 开发与烧录

- 使用 STC-ISP 编译/烧录工程；
- 上电前确认电池极性、舵机供电和 MOSFET 控制极性；
- 首次联调建议先断开机械臂，验证红外解码和舵机角度后再装配；
- 机械结构可使用 PLA 3D 打印，并根据实际墙壁开关调整行程。
